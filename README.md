# Trekking Management Application

A role-based web application built using **Flask**, **SQLite**, **Jinja2**, and **Bootstrap** to simplify trekking management. The system allows **Admins** to manage treks, staff, and bookings, **Trek Staff** to handle assigned treks and participants, and **Users (Trekkers)** to browse, book, and track trekking activities.

### Tech Stack

* **Backend:** Flask
* **Frontend:** HTML, CSS, Bootstrap, Jinja2
* **Database:** SQLite

This project is being developed as part of the **Modern Application Development I (MAD-I)** course at **IIT Madras**.
